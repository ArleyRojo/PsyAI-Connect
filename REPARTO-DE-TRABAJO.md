# 📋 Reparto de Trabajo en Equipo — PsyAI Connect

Este proyecto fue desarrollado en equipo con división de trabajo por capas:

| Rama | Integrante | Responsabilidad |
|------|------------|-----------------|
| `arley` | **Arley Andres Rojo Marín** | **Backend** — Apps Django (modelos, vistas, servicios, repositorios, APIs REST, migraciones), configuración del proyecto, tests, Docker, despliegue y documentación técnica |
| `emmanuel` | **Emmanuel Zapata Arenas** | **Frontend** — Plantillas HTML (Django Templates), estilos CSS, JavaScript, componentes, temas, diseño responsive e imágenes |

La rama `main` contiene el **proyecto completo integrado** (backend + frontend).

**Arquitectura del proyecto:** `Views → Services → Repositories → MySQL` en el backend,
con Bootstrap 5 + CSS modular + JS vanilla (ES6+) en el frontend.

Para ver el aporte de cada integrante: `git checkout arley` o `git checkout emmanuel`.
